# Dezi v2

![Dezi, a cica](media/cica.png)

A cica megjelenítése:

-Telepítsd a bővítményt.

-Nyisd meg a parancspalettát: Ctrl + Shift + P.

-Futtasd a Dezi v2: Cica megjelenítése parancsot.

-Zárd be az összes VS Code-ablakot, majd indítsd újra a programot.

Eltávolítás:

-Futtasd a Dezi v2: Cica eltávolítása parancsot.

-Indítsd újra teljesen a VS Code-ot.

-Ezután már biztonságosan eltávolíthatod a bővítményt.

Fejlesztés:

 `npm test`, `npm run package`. Csomag: `dist/deziv2-0.2.0.vsix`.

A Reload Window önmagában nem mindig frissíti a gyorsítótárazott stíluslapot. A kép közvetlenül az ablakhoz rögzített rétegen jelenik meg.
